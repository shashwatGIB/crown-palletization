# Crown Brewery Palletization

Public dashboard for the Crown Brewery palletization operation, in partnership with InfinityBox.

- `index.html` is the dashboard page. It loads its figures from `data.json` each time it opens.
- `data.json` holds the daily figures from the site's daily production report (DPR). It is refreshed every evening around 9 pm IST.

Live page: https://shashwatgib.github.io/crown-palletization/
